# Сайт МИРЭЯ

Готовый проект на Vite + React + TypeScript + Tailwind.

## Как запустить

```bash
npm install
npm run dev
```

После запуска открой адрес, который покажет Vite в терминале. Обычно это что-то вроде:

```bash
http://localhost:5173/
```

## Как собрать готовую версию

```bash
npm run build
```

Готовая сборка появится в папке `dist`.
